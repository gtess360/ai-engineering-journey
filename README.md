# AI Engineering

A hands-on learning and project repository covering **AI Engineering, Generative AI, LLMs, RAG, AI Agents, Multi-Agent Systems, MCP, AI Automation, Production AI, and Deployment**.

This repository documents the progression from machine learning foundations to the design and development of production-oriented AI systems.

The focus is on **learning by building**: understanding concepts, implementing them in code, experimenting with different approaches, documenting the results, and developing projects that demonstrate practical AI engineering skills.

# Learning Philosophy

The learning process follows:

```text
Concept
   ↓
Demonstration
   ↓
Implementation
   ↓
Experimentation
   ↓
Debugging
   ↓
Improvement
   ↓
```
